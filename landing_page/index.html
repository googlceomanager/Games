FAQ

Got questions?

What is Gridpunk?
Gridpunk is a fast, top-down action shooter set in a cyberpunk universe. It's built around competitive, skill-based multiplayer combat.
Which game modes can I play?
Two: 3v3 Team Battles for tight, competitive squad fights, and a 36-player Battle Royale where the last one standing wins.
Can I play with my friends?
Yes — team up with friends, take on other squads together and chat with players from around the world.
How do I install it?
Click Download to get the Windows installer (Gridpunk-1.0.0.exe), run it, and follow the setup steps.
